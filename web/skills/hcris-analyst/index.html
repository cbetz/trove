hcris-analyst

A Claude Code skill for looking up what U.S. nonprofit hospitals report on two public filings.

Nonprofit hospitals publish a financial-assistance figure on their IRS Form 990 (Schedule H, Part I, line 7a) and a charity-care figure on their Medicare cost report (form 2552-10, Worksheet S-10, line 23). CMS ships cost reports as long CSVs with one row per worksheet cell; the IRS ships returns as XML inside bulk ZIPs. Putting one hospital's two figures next to each other, for the same fiscal period, takes some work.

hcris-analyst is a Claude Code skill that queries the tables where that work is already done. It runs in your own Claude Code session, turns a question into DuckDB SQL against the published data files, and shows the two figures with the components from each filing that show what is in the difference.

Install

Install the trove plugin (version 1.2.0) from Anthropic's public community marketplace:

/plugin marketplace add anthropics/claude-plugins-community
/plugin install trove@claude-community

trove is listed in the community marketplace, not the separate official claude-plugins-official marketplace. The skill's source, and instructions for installing it without the plugin, are at github.com/cbetz/trove/tree/main/skills.

A worked example

The question, the query the skill's reference file gives for it, and the result from the current data files (run on 2026-11-19).

Question

"What did Yale New Haven Hospital report on Schedule H line 7a and on S-10 line 23, and what is in the difference?"

Query

SELECT hospital_name, city, state, ein, ccn_list AS ccn,
       sched_h_tax_period_end::DATE AS irs_period_end,
       hcris_fy_end_dt::DATE        AS cms_period_end,
       period_aligned,
       sched_h_financial_assistance_gross::BIGINT          AS irs_7a_c_total_expense,
       sched_h_financial_assistance_offset_revenue::BIGINT AS irs_7a_d_offsetting_revenue,
       sched_h_financial_assistance_at_cost::BIGINT        AS irs_7a_e_net,
       hcris_charity_care_cost_uninsured::BIGINT AS cms_line23_col1_uninsured,
       hcris_charity_care_cost_insured::BIGINT   AS cms_line23_col2_insured,
       hcris_charity_care_cost::BIGINT           AS cms_line23_col3,
       hcris_medicaid_dsh_supplemental::BIGINT   AS cms_line5,
       charity_gap::BIGINT                       AS cms_minus_irs_net
FROM read_parquet('https://troveproject.com/data/community_benefit_gap_2022.parquet')
WHERE ein = '060646652';

How the skill is told to read it

Both filings cover the fiscal year ending 2023-09-30. The return lists $257,262,512 of total expense and $144,162,000 of direct offsetting revenue on line 7a, for a net of $113,100,512. The cost report lists $35,568,680 on S-10 line 23 column 3 ($30,287,094 uninsured, $5,281,586 insured) and −$71,469,000 on S-10 line 5. The skill's reference file gives this wording for the difference:

Of the $77.5M difference, about $71.5M appears to be Connecticut's hospital provider tax net of the state supplemental payments it funds: the amount on S-10 line 5, which the cost report keeps separate from charity care. The worksheet behind the IRS line is not public, so this is a reconciliation from the hospital's own filings, not a figure the hospital has stated.

The skill reports these as "not reported on this line": The Johns Hopkins Hospital's cost report includes a Worksheet S-10 with no value on line 23, and St. Jude's cost report has no Worksheet S-10. Neither is shown as $0, and no difference is computed.

What this skill does

  • Knows the data files. The matched table (one row per EIN, 51 columns), the ranked index, CMS cost reports from the fiscal year 2022 and 2023 files in wide format, and every tax year 2022 Schedule H found in the IRS e-file releases for 2023 through 2026.
  • Shows the components, not just two totals. IRS line 7a columns (c), (d) and (e); CMS S-10 line 23 columns 1, 2 and 3; S-10 line 5. It compares the size of the difference with each component and says what the filings show.
  • Labels a reconciliation as a reconciliation. When components appear to account for a difference, the skill says this comes from the two filings and is not a statement by the hospital. When nothing in the filings accounts for it, the skill says that and leaves it as a question.
  • Uses the matched fiscal period. CMS groups cost reports into fiscal-year files by the date the reporting period begins. The matched table already holds, for each CCN, the report whose period ends closest to the 990's, and a period_aligned column says whether the two end within one month.
  • Keeps missing separate from zero. A line with no value on the form is "not reported on this line". It is never shown as $0 and gets no difference.
  • Handles multi-hospital systems. One EIN can cover several CCNs. The CMS figure is then a sum across cost reports, a total is given only when every CCN reports the line, and those rows are in the lookup but not in the ranked index.
  • Disambiguates names and gives links to both filings: the return's Schedule H on ProPublica Nonprofit Explorer and the provider's record on data.cms.gov.

What this skill doesn't do

  • Say that either figure is wrong. The two lines are defined differently, so they can differ when both are filed correctly. The worksheet behind the IRS line is not public.
  • Staffing, wages, teaching status, quality or outcomes. None of these are in the data files. Quality measures are in CMS Care Compare.
  • Trends. The files hold tax year 2022 and the two CMS fiscal-year files that overlap it.
  • The IRS figure for for-profit and government hospitals. They file cost reports, so the skill can answer cost-report questions about them, but they file no Schedule H.

Coverage

2,099 nonprofit hospital systems matched at the EIN level, of which 1,904 have both figures and 1,797 of those cover the same fiscal period on both filings. The ranked index is the 493 single-hospital rows, in 48 states, where the two lines can be set side by side; 107 of them differ by more than 50% of the larger figure. Sources: CMS HCRIS Hospital 2552-10 files for fiscal years 2022 and 2023 (CMS extract generated 2026-10-02, posted 2026-10-05); IRS Form 990 Schedule H, tax year 2022, from e-file releases 2023–2026; CCN-to-EIN crosswalk from Community Benefit Insight (RTI International / RWJF), December 2024.
