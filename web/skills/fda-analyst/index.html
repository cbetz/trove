fda-analyst

A Claude Code skill for FDA novel drug approvals.

The FDA publishes an approval package for each newly approved drug — medical review, statistical review, pharmacology review, chemistry review, label, and other documents that describe the basis for the agency's decision. The documents are public on accessdata.fda.gov, but the path from "drug name" to "the medical review that explains why this drug got approved" is several clicks of guesswork through FDA's site.

fda-analyst is a Claude Code skill that knows where those documents live, how to identify the right one for a given question, and how to read and cite the relevant section. It runs in your own Claude Code or Claude Desktop session and fetches FDA PDFs at query time — no preloaded summaries, no training-data approximations.

Install

Install the trove plugin (version 1.1.0) from Anthropic's public community marketplace:

/plugin marketplace add anthropics/claude-plugins-community
/plugin install trove@claude-community

trove is listed in the community marketplace, not the separate official claude-plugins-official marketplace. The skill's source, and instructions for installing it without the plugin, are at github.com/cbetz/trove/tree/main/skills.

Example prompts

  • "What was the basis for Lenmeldy's approval — what trials, what endpoints?"
  • "What adverse events did the FDA flag in the Elahere medical review?"
  • "Was Krazati approved via accelerated approval? What was the pathway?"
  • "Compare the regulatory pathways used for Aduhelm and Leqembi."
  • "Which 2023 approvals used a single-arm trial as the pivotal evidence?"
  • "What was the primary endpoint in the Vyvgart approval?"

A worked example

The question, the commands the skill's reference files give for it, and their output (run on 2026-11-19). fda_package_base, fda_probe and fda_get are small shell helpers defined in the skill; they send the User-Agent FDA's document server requires and accept only a real PDF.

Question

"What was the basis for Zurzuvae's approval?"

1. Find the application in the index

SELECT drug_name, active_ingredient, sponsor, application_type, application_number,
       approval_date, regulatory_center, drugs_at_fda_url
FROM read_parquet('https://troveproject.com/data/fda_approvals_nme_recent.parquet')
WHERE LOWER(drug_name) = 'zurzuvae';
         drug_name = Zurzuvae
 active_ingredient = zuranolone
           sponsor = Biogen INC
  application_type = NDA
application_number = 217369
     approval_date = 2023-08-04
 regulatory_center = CDER
  drugs_at_fda_url = https://www.accessdata.fda.gov/scripts/cder/daf/index.cfm?event=overview.process&ApplNo=217369

2. Read the package location from FDA's overview page, then check the review exists

BASE=$(fda_package_base 217369); echo "BASE=$BASE"
fda_probe "${BASE}IntegratedR.pdf"
BASE=https://www.accessdata.fda.gov/drugsatfda_docs/nda/2023/217369Orig2s000
OK 21.3 MB https://www.accessdata.fda.gov/drugsatfda_docs/nda/2023/217369Orig2s000IntegratedR.pdf

This package is published as Orig2s000, not the usual Orig1s000, which is why the skill reads the location from the overview page instead of guessing it.

3. Download once, then read page ranges

fda_get "${BASE}IntegratedR.pdf" review.pdf
pdfinfo review.pdf | grep Pages
pdftotext -f 34 -l 34 -layout review.pdf - | grep -A3 "2.2. Conclusions"
Pages:           416
2.2. Conclusions Regarding Benefit-Risk
In NDA 217369 for zuranolone oral capsules, the Applicant is seeking indications for the
treatment of major depressive disorder (MDD) and for the treatment of postpartum depression
(PPD).

From there the skill reads the benefit-risk section and the efficacy tables it points to, and answers with the document name and page for each fact it quotes. A 416-page review is read in page ranges, not loaded whole.

What this skill does

  • Finds the application. The skill queries trove's FDA approvals index (a Parquet bundle with 217 novel drug approvals from 2021–2024: 192 from CDER and 25 CBER cell & gene therapies) to locate the application number, sponsor, and approval-package URL for the drug in question.
  • Picks the right document. Different questions need different documents — the medical review for "basis for approval" and "adverse events", the statistical review for endpoint analyses, the pharmacology review for ADME, the chemistry review for manufacturing. The skill knows the mapping.
  • Reads it at query time. No pre-extracted summaries. The skill fetches the PDF from FDA's site, checks its size, reads the relevant section (in page ranges when the review is large), and quotes back with a citation.
  • Cites the source. Answers reference the specific document and page so users can verify.

What this skill doesn't do

  • Clinical advice or dosing. It's a reference tool over public approval documents, not a substitute for the prescribing label or clinical judgment.
  • Drugs first approved before 2021 or after 2024. The index covers original approvals dated 2021–2024.
  • Devices, biosimilars, or generic (ANDA) approvals. The trove index covers FDA's curated Novel Drug Approvals lists (NMEs and novel BLAs) only.
  • Work without network access to FDA. The review documents have no mirror. In a sandbox that cannot reach www.accessdata.fda.gov or www.fda.gov, the skill gives you the document URL and asks you to allow the domain or upload the PDF.

Coverage

217 FDA novel drug approvals with an original approval date in 2021–2024: 192 CDER (small molecules and most antibody biologics) plus 25 CBER (cell & gene therapies). Browse the index at /drugs/ — each drug has its own permalink page with the approval-package URL, e.g. /drugs/elahere/, /drugs/leqembi/, /drugs/lenmeldy/, /drugs/casgevy/.
