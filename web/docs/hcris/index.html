What is HCRIS?

CMS Medicare Cost Reports — the financial filing every Medicare-participating hospital submits annually.

HCRIS stands for the Healthcare Cost Report Information System. It's the public CMS database of annual Medicare Cost Reports — the financial, operational, and utilization filings that every Medicare-participating hospital is required to submit. HCRIS is one of the most widely cited datasets in U.S. hospital research, and one of the hardest to use in its raw form.

Why HCRIS exists

Medicare uses cost reports to set and update payment rates, and still pays some hospitals on the basis of cost. To do that, CMS requires every participating provider to file an annual cost report listing what they spent, what they earned, and on whom. The reports also feed Medicare's disproportionate-share hospital (DSH) payments, which compensate hospitals that serve a high share of low-income patients. The data is collected for regulatory purposes, but because the underlying filings are public, HCRIS has become the default source for almost any quantitative question about U.S. hospitals.

What gets filed

Hospitals file CMS Form 2552-10, a set of worksheets with several thousand cells. The main series are S (identification, statistics and settlement summary), A (expenses), B (cost allocation), C (charges and cost-to-charge ratios), D (apportionment of cost to Medicare), E (settlement) and G (financial statements), with further series for provider-based units such as home health agencies and hospices. Other provider types (skilled nursing facilities, home health agencies, hospices, federally qualified health centers) file their own forms. Trove covers Hospital 2552-10.

A handful of worksheets carry most of what hospital research uses:

  • Worksheet S-2: hospital name, type of control (nonprofit, proprietary, governmental), home office.
  • Worksheet S-3: beds, bed days, discharges, and wage and FTE data.
  • Worksheet S-10: Medicaid revenue and cost, charity care, bad debt, uncompensated care.
  • Worksheet G: balance sheet.
  • Worksheets G-2 and G-3: patient revenue, operating expenses, net income.

Worksheet S-10: charity care, and what is kept separate from it

  • Line 23 is the cost of charity care after patient payments: uninsured patients in column 1, insured patients in column 2 (deductibles and coinsurance written off), and the total in column 3.
  • Line 5 is Medicaid DSH and supplemental payments "net of associated provider taxes or assessments". Line 5 holds the payments not already included in line 2 (Medicaid revenue); neither line is part of line 23. It is negative when the provider taxes are larger than the payments.
  • Line 30 is total uncompensated care cost: line 23 column 3 plus line 29, non-Medicare and non-reimbursable Medicare bad debt.

Line 23 column 3 is the CMS figure that trove shows next to IRS Form 990 Schedule H, Part I, line 7a. The two lines are defined differently, so they can differ when both are filed correctly. The hospitals page walks through one hospital's two figures and the components behind the difference.

The worksheet code changed. Cost reports for periods beginning before 2022-10-01 carry Worksheet S-10 under the code S100000. For later periods the worksheet is split in two parts and Part I, which covers the whole hospital complex as the old worksheet did, is S100001. The line and column numbers used here are the same in both. Trove maps both codes to the same variables.

Why HCRIS is hard to use

CMS distributes HCRIS as ZIP files, where each ZIP contains long CSVs with one row per (report, worksheet, line, column, value). A single hospital's annual filing becomes thousands of rows. To do anything analytical you have to pivot the data wide, joining the right (worksheet, line, column) triples to get something like "cost of charity care" as a column.

The line and column codes are documented in CMS's Provider Reimbursement Manual (Pub. 15-2, Chapter 40). The documentation is long, and CMS sometimes renumbers a worksheet between form revisions. Trove ships a 52-variable dictionary that names commonly used fields and resolves each to its (worksheet, line, column) source.

Fiscal-year files are keyed on when the period begins

CMS groups cost reports into fiscal-year files by the date the reporting period begins: the FY2023 file holds periods beginning 2022-10-01 through 2023-09-30. A calendar-2022 report is in the FY2022 file; a report for October 2022 to September 2023 is in FY2023. So one hospital's "2022" figure can be in either file, depending on its fiscal year. To set a cost report next to a tax year 2022 Form 990, trove loads both files and, for each provider, takes the report whose period ends closest to the end of the 990's tax period. A row counts as period-aligned when the two end dates are within one month.

A blank is not a zero

CMS's numeric file does not store zero values. When a cost report has no value on a line, the line is simply absent, and that can mean the hospital entered zero, left it blank, or did not file the worksheet. Trove keeps these as missing: a hospital with no value on S-10 line 23 is shown as "not reported on this line", never as $0. For example, The Johns Hopkins Hospital files a Worksheet S-10 with no value on line 23, and St. Jude Children's Research Hospital and Texas Children's Hospital have no Worksheet S-10 in the CMS file.

What HCRIS doesn't include

  • Quality and outcomes measures. Readmissions, mortality, complication rates are in CMS Care Compare, not HCRIS.
  • Patient-level data. HCRIS is hospital-level aggregates, not encounters.
  • Hospitals that don't file a Medicare cost report. Veterans Affairs and military hospitals, for example.
  • Community benefit beyond charity care. Research, education, Medicaid shortfall and other categories are reported by tax-exempt hospitals on IRS Form 990 Schedule H.

How to use HCRIS data

Three paths, in order of effort:

  • Query trove's published Parquet files with DuckDB over HTTPS. There is one file per CMS fiscal-year file, one row per cost report: 
    SELECT prvdr_num, hospital_name, fy_bgn_dt, fy_end_dt,
       total_beds, charity_care_cost
FROM read_parquet(
  'https://troveproject.com/data/hcris_2023_wide.parquet')
WHERE prvdr_num = '070022';
    The fiscal year 2022 file is hcris_2022_wide.parquet at the same address. The hospitals page shows the cost report figure next to the IRS figure for 2,099 matched nonprofit hospital systems.
  • Install the hcris-analyst Claude Code skill to ask questions in plain language: "Show S-10 line 23 and Schedule H line 7a side by side for Yale New Haven Hospital" or "What does Worksheet S-10 line 5 mean?"
  • Download from CMS directly and pivot it yourself. The trove repository (github.com/cbetz/trove) has the parser and the dictionary if you want to reproduce or extend the work.

Columns in trove's HCRIS files

Each row is one cost report. Besides the 52 dictionary variables (beds, discharges, revenue, expenses, the S-10 lines, name, type of control, home office), every row carries:

  • hcris_file_fy: which CMS fiscal-year file the report came from.
  • rpt_rec_num, prvdr_num: CMS's report record number and the provider's CCN.
  • fy_bgn_dt, fy_end_dt: the cost reporting period.
  • rpt_stus_cd, rpt_status: report status (as submitted, settled without audit, settled with audit, reopened, amended).
  • proc_dt: the date CMS processed the report.
  • s10_filed: whether the report has a Worksheet S-10 at all.

The full variable list, with the worksheet, line and column for each, is in the field dictionary on GitHub.
